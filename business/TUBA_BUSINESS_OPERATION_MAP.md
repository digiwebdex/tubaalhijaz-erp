# TUBA AL HIJAZ — Business Operation Map

**Document type:** Company Operating Manual  
**Audience:** Operations Director and all department leads  
**Authority:** Derived from the Master Business Blueprint and real Excel/Word practice

# Part A — End-to-End Journey

## A1. How one journey begins and ends

```
Agent
  → Customer (Mutamer)
  → Passport
  → OCR / Group intake
  → Group Assignment
  → Package
  → Visa
  → Supplier (Umrah Co)
  → Hotel
  → Transport
  → Catering
  → Voucher
  → Saudi Arrival
  → Service Delivery (stay, ziyarah, moves)
  → Return / Departure
  → Finance Settlement
  → Reports & Archive
```

---

## A2. Stage-by-stage operation

### 1) Agent

**Who:** Bangladesh travel agency (e.g. Discover Holidays) — customer of Tuba.  
**What they do:** Collect pilgrims in Bangladesh; request Umrah/Hajj/Long Stay service through Tuba; work under Tuba’s Main External Agent identity in Nusuk.  
**Tuba duty:** Verify agent relationship; keep one shared group register; never mix agents’ groups.

### 2) Customer (Mutamer)

**Who:** Pilgrim / traveller.  
**Rule:** Customer never operates Tuba’s system. Agent or Tuba Staff enter everything.  
**What is captured later:** Name, age, passport, nationality, Sub EA, visa/biometric/MOFA status, type (often B2B).

### 3) Passport

**What:** Identity document for each mutamer.  
**Ops rule:** Passport number is the identity key; duplicates in a group must be caught.  
**Path:** Scan/photo for OCR and/or listed in mutamer Excel.

### 4) OCR / Group intake

**Morning of a new group (typical):**

1. Agent or Staff obtains **Nusuk Group Number** (or asks Tuba to create from Nusuk Groups List image).  
2. Image is read (OCR) and checked by a human.  
3. **Group Number is opened** in Tuba’s register — unique, shared Staff ↔ Agent.  
4. Manual fields added: Visa type (Hajj / Umrah / Long Stay), **Haji/reference WhatsApp (mandatory)**, Umrah Company, Agent name.

### 5) Group Assignment

Group becomes the **spine**. Everything after this points to the Group Number:

- Mutamer list  
- Package & readiness gates  
- Visa / Hotel / Transport / Catering  
- Voucher, arrival, stay, return  
- Bills and dues  

**Readiness gates on the group board:** VISA · PACKAGE · PAYMENT · BILL  

### 6) Package

**What:** Commercial/ itinerary package for the group (economy/standard/premium style, or Long Stay package).  
**Ops action:** Confirm package contents (visa only vs hotel+transport+catering); flip **PACKAGE** gate when package is locked for ops.

### 7) Visa

**Who drives:** Visa Desk + Saudi **Umrah Company** (Habash, Almautmirin/Al Olayan, Arkan, …).  
**Mutamer tracking:** Biometric status → Visa status → Visa Number → MOFA Number.  
**Long Stay extra:** Host/Service Holder (Iqama, WhatsApp mandatory), relation (Husband/Wife/Relatives), ~90 days, Absher flag.  
**Gate:** Flip **VISA** when visa work for the group is acceptably complete.

### 8) Supplier

Four kinds of suppliers Tuba works with:

| Type | Role |
|------|------|
| Umrah Company | Visa / Nusuk-side processing |
| Hotel | Makkah & Madinah stay |
| Transport | Airport, city, ziyarah moves |
| Catering | Meals |

Ops assigns suppliers **by Group Number**. Suppliers confirm or reject assigned work.

### 9) Hotel

**Dual city when needed:**

| Block | Track |
|-------|--------|
| Makkah | Hotel name, Agreement/BRN No., check-in/out, pax, STATUS |
| Madinah | Same |

**STATUS language:** WAITING FOR APPROVAL → APPROVED  

BRN inventory (agreements bought) feeds Agreement Numbers; used pax tracked against capacity.  
**Commercial note:** Hotel/transport stay may be **cash as discussed**; separate from MOFA processing bill.

### 10) Transport

1. **Request** from Agent/Staff: vehicle type, FULL vs SINGLE, route, flights, hotels, ziyarah dates, ticket copies, payment receipt, contact.  
2. **Schedule board** built by Transport Desk: legs (airport↔hotel, MAK↔MED, ziyarah), time, flight, transport company (or Own Transport), BILL mark, done flag.  
3. Operation/booking numbers recorded.

### 11) Catering

If package requires meals: assign Catering supplier (e.g. Tuba Al-Hijaz Catering), dates, pax, dietary notes; confirm fulfilment before arrival peak.

### 12) Voucher

When hotel + transport plan is solid, Ops issues the **bilingual Transport Voucher**:

- Agent, country, Umrah Co, Group Code, Muallim mobile  
- Makkah & Madinah hotels (nights, rooms, agreements)  
- Transport company, vehicle, booking no., pax  
- Arrival & departure flights  
- Internal movements list  
- Supervisors’ mobiles + 24h ops numbers  

Voucher is the field authority for drivers and hotel side.

### 13) Saudi Arrival

**Day of arrival:**

1. Arrival board: flight, airport (JED/MED), time, pax, group, hotel.  
2. Meet & assist / dispatch vehicle per schedule.  
3. Move mutamers Airport → Hotel.  
4. Mark schedule leg done; escalate delays.

### 14) Service Delivery (stay)

During stay Ops runs:

- Hotel check-in/out discipline  
- Internal MAK↔MED transfers  
- Ziyarah trips  
- Catering delivery windows  
- Long Stay: Absher, Host contact, **day-85 reminders** (Host + Agent + Tuba WA/email + red dashboard cards)  
- Incident / medical / lost mutamer escalations via 24h ops numbers  

### 15) Return

**Departure day:**

1. Departure board: flight, airport, hotel pickup time.  
2. Hotel → Airport move.  
3. Confirm all pax on flight.  
4. Close transport legs; note no-shows.

### 16) Finance Settlement

After (and sometimes during) the journey:

1. **Credits** only from **Agent** or **Host** (Long Stay).  
2. **Debits** to suppliers with source: bank / cash / mobile banking.  
3. **MOFA Processing Bill** (Qty × Rate) — separate from cash hotel/transport.  
4. Approval Sign + CR Date on MOFA bills.  
5. Group gates **PAYMENT** and **BILL**.  
6. Track **Due from Agent** until cleared.

### 17) Reports & Archive

Close the loop:

- Group dossier by Group Number  
- Agent-wise / supplier-wise summaries  
- Income & expense (daily / monthly / yearly views)  
- Season archive (live board vs old season)

# Part B — Rhythm of the Company

## B1. Daily Operations

### Morning (before peak arrivals / desk open)

| Time focus | Action |
|------------|--------|
| Command view | Due from agents; groups in process; Long Stay red cards; hotels waiting approval |
| Arrival board | Today’s inbound flights, pax, hotels, vehicles |
| Transport | Confirm vehicles/drivers/companies for morning legs |
| Visa | Chase biometric/visa stuck mutamers for groups arriving ≤72h |
| Hotel | Confirm APPROVED status for today’s check-ins |
| Notifications | Send/verify overnight material alerts; escalate failed WA |
| Finance | Cash position note; pending MOFA bill approvals |

### Afternoon (execution)

| Focus | Action |
|-------|--------|
| Live moves | Airport↔hotel, MAK↔MED, ziyarah per schedule |
| Delays | Reassign vehicles; notify Agent WhatsApp |
| New intake | OCR/group create; mutamer Excel uploads |
| Supplier | Accept/reject follow-ups; BRN allocation if new hotels |
| Vouchers | Issue for groups departing next 24–48h if not done |
| Long Stay | Update Absher/remarks; watch day-85 list |
| Catering | Confirm tomorrow’s meal counts |

### Evening (close of day)

| Focus | Action |
|-------|--------|
| Departure close | All return flights reconciled |
| Schedule | Mark done/BILL flags; list incomplete legs |
| Gates | Update VISA/PACKAGE/PAYMENT/BILL where truth changed |
| Finance | Post supplier payments with source; record agent credits |
| Handover | Night ops / 24h numbers briefed on open incidents |
| Report stub | Daily movement + exception log |

---

## B2. Weekly Operations

| Day theme (illustrative) | Work |
|--------------------------|------|
| Week start | Forecast next 7 days arrivals/departures; vehicle & hotel load |
| Mid-week | BRN capacity review; Umrah Co backlog meeting |
| Agent sync | WhatsApp/call top agents on dues & pending visas |
| Quality | Spot-check vouchers vs schedule vs hotel approvals |
| Finance | Weekly dues chase; MOFA bills batch approval |
| Compliance | Long Stay day-85/90 list for the week; Absher incomplete list |
| HR | Attendance & advance salary requests (if any) |
| Week end | Weekly income/expense snapshot; exception report to Director |

---

## B3. Monthly Operations

1. **Month close finance** — income, expense, agent dues aging, supplier payables.  
2. **Season progress** — groups completed vs active; mutamer volume.  
3. **Supplier scorecard** — rejects, delays, voucher issues.  
4. **BRN inventory** — used vs bought capacity; renew agreements.  
5. **Agent performance** — volume, dues behaviour, Excel/data quality.  
6. **Long Stay compliance audit** — any missed day-85.  
7. **HR payroll** — salaries posted; staff list updates.  
8. **Director pack** — monthly reports (agent/supplier/group/income/expense).

---

## B4. Yearly / Season Operations

1. Open new Hijri/Umrah season board; archive prior season groups.  
2. Refresh Umrah Co / hotel / transport / catering master lists.  
3. Reset or renew BRN purchasing strategy.  
4. Agent re-verification / commercial terms.  
5. Rate card review (MOFA processing rates, transport packages).  
6. Annual income/expense; payroll summary.  
7. Training refresh on Group Number discipline & day-85.  
8. Policy review: WhatsApp mandatory fields, cash vs MOFA split.

# Part H — Long Stay special operating strip

```
Day 0  Entry / visa start
  …
Day 85 REMINDER PACK (non-negotiable)
         → Host WhatsApp
         → Agent WhatsApp
         → Tuba official WhatsApp
         → Email
         → Red card on Agent + Tuba dashboards
Day 90 Expected exit window
```

Ops must review the day-85 list **every morning**.

# Part I — Finance operating strip

```
Agent / Host money in  →  CREDIT only
Supplier money out     →  DEBIT + source (bank / cash / mobile)
MOFA Processing Bill   →  Qty × Rate → Approval Sign → CR Date
Hotel/Transport stay   →  Often cash-as-discussed (not the MOFA bill)
Group board            →  PAYMENT + BILL gates
Director               →  Due from Agent always visible
```

# Part J — One-page “perfect group” checklist

- [ ] Unique Group Number shared Staff ↔ Agent  
- [ ] Visa type + Umrah Co + Agent set  
- [ ] Mandatory WhatsApp (Haji or Host) present  
- [ ] Mutamer Excel complete (passport, Sub EA, statuses)  
- [ ] PACKAGE gate true when package locked  
- [ ] VISA progressing / gate when done  
- [ ] Makkah/Madinah hotels APPROVED with Agreement Nos.  
- [ ] Transport request + schedule + voucher issued  
- [ ] Catering confirmed if in package  
- [ ] Arrival executed; stay delivered; return executed  
- [ ] PAYMENT/BILL gates + MOFA bill signed as applicable  
- [ ] Agent/Host dues cleared or aged visibly  
- [ ] Long Stay day-85 done if LS  
- [ ] Group closed / season archive
